## 📌 Project Overview

This project is a **full-stack WhatsApp Clone** that replicates the core features of modern messaging applications including **real-time chat, voice calls, video calls, and modern responsive UI**.

The goal of this project is to demonstrate **real-time communication systems**, **WebRTC based calling**, and **full-stack application architecture** using modern web technologies.

The application works on both **desktop and mobile browsers** with a responsive interface.

---

## ✨ Features

### 💬 Messaging
- Real-time one-to-one messaging
- Instant message delivery using sockets
- Chat history
- Responsive chat interface

### 📞 Voice Calls
- Peer-to-peer voice calls
- Low latency audio streaming
- Smooth call experience

### 🎥 Video Calls
- Real-time video communication
- Local and remote video streams
- WebRTC based implementation

### 📢 Updates Section
- App announcements
- Feature update messages
- Global messages visible to all users

### 🧑‍🤝‍🧑 Communities / Contacts
- Chat with multiple contacts
- Contact list view

### 📱 Responsive UI
- Works on desktop browsers
- Mobile friendly layout
- Modern UI similar to WhatsApp
